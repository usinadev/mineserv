# Plugins do Servidor

Este diretório é para plugins do Paper/Spigot.

## 📦 Plugins Recomendados

### Performance
- **Spark** - Monitoramento de performance
- **ClearLag** - Limpeza automática de entidades
- **FarmControl** - Controle de farms

### Utilidades
- **EssentialsX** - Comandos essenciais
- **WorldEdit** - Edição de mundo
- **Vault** - Economia e permissões

### Segurança
- **CoreProtect** - Log de ações
- **LuckPerms** - Sistema de permissões
- **WorldGuard** - Proteção de áreas

### Administração
- **ProtocolLib** - Necessário para muitos plugins
- **PlugMan** - Gerenciamento de plugins
- **ConsoleFilter** - Filtro de console

## 🚀 Instalação

1. Baixe o plugin `.jar`
2. Coloque neste diretório
3. Reinicie o servidor

```bash
docker-compose restart
```
